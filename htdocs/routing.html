ImpressCMS

The web server needs one more setting

ImpressCMS needs every PHP request to be sent to index.php. This web server still runs the requested script itself, so the page cannot be shown.

Apache or LiteSpeed

Rename htaccess.txt in the web root to .htaccess. If you already have a .htaccess, copy the <IfModule mod_rewrite.c> block of htaccess.txt into it. The server needs mod_rewrite and must allow .htaccess files (AllowOverride).

nginx

location / {
    try_files $uri $uri/ /index.php$is_args$args;
}
location ~ \.php$ {
    include fastcgi_params;
    fastcgi_param SCRIPT_FILENAME $document_root/index.php;
    fastcgi_param SCRIPT_NAME /index.php;
    fastcgi_pass php;   # your PHP-FPM upstream
}

FrankenPHP or Caddy

@php path *.php
rewrite @php /index.php
php_server

The complete example configurations, including the folders that must never be served, are in docs/server. Reload this page once the server is configured.

Your content and database are untouched. On shared hosting without access to the server configuration, ask your hosting provider to enable .htaccess rewriting.
